# Bounded compact prompt

The authenticated restricted-agent policy may explicitly select
`compact_system_prompt` only with `structured_output_only` and exactly one
registered tool. Default policy and normal agents retain the full system prompt.

Only a trusted operator HTTP control prompt with a matching canonical Conversation
execution binding and no Work, task, delegated identity or operator reply route
uses compact assembly. Unknown or ineligible execution ownership falls back to
full assembly. Other sources stay queued rather than interjecting or live-attaching into an
actually bounded turn. Full fallback retains normal input admission. The mode actually selected for the current turn is frozen for prompt and input
admission, including full fallback. Work focus pick is rejected while that turn
is bounded; normal full turns retain existing behavior. The prompt and input
paths share the authenticated current-turn predicate before selection. Source-text
engineering keywords do not generate repair system instructions in bounded mode. They retain their own claim and ownership rules.

The compact system replaces unavailable engineering, planning, Work, scheduling,
App and user-facing reporting tutorials with a bounded structured-request contract.
It retains actual scoped guidance and native memories, instruction precedence,
trust boundaries, canonical agent authority, execution environment and language.
Unknown upstream system sections pass through. Loaded source deduplication,
context projection, tool descriptions/schemas and bridge authorization are unchanged.
The registered tool is not an independent grant of permission for external effects.

The policy does not alter model reasoning, native capability enforcement, action
admission, validation, settlement or cleanup. It is a prompt composition choice,
not a smaller capability sandbox. The caller owns the one-shot lifecycle and
must validate submission evidence independently of assistant prose. Upstream edits
to omitted sections require re-evaluating this bounded eligibility contract.
